## 演示边界

- 12 个项目、420 条任务、模型标签和运行状态均为合成数据，不代表作者账号或真实性能。
- 交互通过现有前端控件完成，没有用后期动画冒充产品功能。
- 录制服务仅将数据来源文字改为“演示”，并加上持续可见的“演示数据 · 无真实聊天”标记；正式应用未因此修改。
- GIF 为便于首页展示而降低帧率并压缩颜色；高清细节以 MP4 和 WebP 为准。
- 动图和视频不构成对其他电脑上的 Codex 实时连接、兼容性或性能的验证。
